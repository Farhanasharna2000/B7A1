## 🛠 Code Solutions (`solutions.ts`)

The `solutions.ts` file addresses several core programming challenges using TypeScript features:

### 1. Array Manipulation
- `filterEvenNumbers`: Filters even numbers from an array using `.filter()`.
- `getIntersection`: Returns common elements between two arrays using `.includes()`.

### 2. String Utilities
- `reverseString`: Reverses a given string for basic data transformation.

### 3. Type Guarding
- `checkType`: Uses type narrowing to handle union types (`string | number`).

### 4. Generics
- `getProperty`: Uses `keyof` and generics to ensure type-safe object property access.

### 5. Interface Extension
- `toggleReadStatus`: Demonstrates returning an intersection type  
  (`Book & { isRead: boolean }`).

### 6. OOP Foundations
- `Person` class and `Student` subclass showcasing inheritance and constructor logic.
